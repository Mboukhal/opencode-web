1. Get the app

OpenCode Mobile is a remote for OpenCode on this computer. Your sessions keep running here; the app shows them and lets you steer them.

iPhone (TestFlight) Android (Play Store)

2. Create a pairing link

The link works once and expires in 5 minutes. Scan the QR code with the app, or open the link on the phone.

{{.Data.QR}}

Expires 5 minutes after it was created.

3. Or use the terminal on this server

Pairing codes can also be printed from the command line:

opencode pair --remote --yes

--remote routes through an OpenTunnel address so the phone works from any network. The server here listens on {{.Data.ServerAddr}}.
